Crie um MCP que acesse a API pública do youtube, sem exigir autenticação, para obter todos os shorts de uma determinada conta. Para cada short dessa lista, traga as informações básicas junto com o número de visualizações e o número de curtidas.

Caso a resposta venha paginada, percorra o máximo de páginas possível. Se ocorrer algum erro de acesso durante esse processo, ignore-o e prossiga, armazenando apenas o que foi possível baixar.

A lista de shorts deve ser salva em resources/shorts/<conta>/lista_shorts.csv e organizada por ordem de publicação, do vídeo mais novo para o mais antigo. O MCP poderá ser executado mais de uma vez e, quando isso acontecer, basta atualizar a lista inserindo os vídeos mais recentes no início.

Utilize Node.JS (javascript) e salve o MCP na pasta resources/mcps/<nome do mcp>.

Realize um teste com essas conta do youtube @FabricioPacholok e @marcioatalla

## Orientações técnicas

- Não use login, sessão autenticada, cookies manuais, Playwright ou Puppeteer. Use apenas chamadas HTTP públicas via Node.js.
